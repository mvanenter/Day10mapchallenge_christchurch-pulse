
# Christchurch Pulse
 
**#30DayMapChallenge 2026, Day 10: Prompt only**
 
An animated "pulse" map of Ōtautahi Christchurch. Buses travel along real Metro route shapes across the urban area while a glowing heart pulses at the city centre.
 
**Location:** Ōtautahi / Christchurch, New Zealand
**Built with:** Leaflet, HTML and CSS, generated entirely by prompting an AI (Grok)
 
## What it shows
 
- Christchurch City urban extent
- Street centre lines clipped to the urban extent
- Real bus route shapes from Environment Canterbury, clipped to the urban extent
- Bus stops
- Animated buses that follow the route geometries, each labelled with its Metro route number
- A route key listing each route's colour, number and name, using Environment Canterbury's official colours
- A pulsing heart marking the city centre
The buses are illustrative. They show where the routes run, not live vehicle positions or real timetables.
 
## How it was made
 
Day 10 of the #30DayMapChallenge was "Prompt", so the goal was to see how far pure prompting could go with no hand-written map code.
 
1. Started with a simple request for a Christchurch version of a cinematic "pulse" map
2. Refined the idea through conversation: dark style, urban extent, roads, real routes, bus stops, basemap
3. The AI wrote the complete self-contained HTML and Leaflet page
4. Clipping the routes and roads to the urban extent was also done with prompted Python scripts
5. Later refinements removed the time slider and the generated timetable, which did not match real services, and enlarged the title
The skills being tested were prompt writing, data selection, iterative refinement and spatial judgement, rather than traditional GIS scripting.
 
## Data sources
 
- Christchurch City Council Open Data: Urban Extent
- Christchurch City Council Open Data: Street Centre Line
- Christchurch City Council Open Data: Bus Stops
- Environment Canterbury: Bus Route Directions (https://gis.ecan.govt.nz/arcgis/rest/services/Public/Bus_Routes/MapServer/3), route numbers and names
- Basemap: Esri World Dark Gray Canvas
## Run locally
 
```
python -m http.server 8000
```
 
Then open http://localhost:8000 in a browser.
